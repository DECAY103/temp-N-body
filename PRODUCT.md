# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Standalone Vanilla HTML5, Three.js, and CSS/JS (zero build step; self-contained web deliverables generated by simulation scripts or standalone viewer).

## Users
HPC researchers, computational astrophysicists, peer evaluators, and parallel computing students analyzing 3D gravitational N-body simulations, Octree performance, and domain decomposition across MPI ranks.

## Product Purpose
Provide an interactive, GPU-accelerated 3D visualizer and telemetry analysis dashboard for the AL-BH (Adaptive Linearized Barnes–Hut) simulator. Enables researchers to inspect cosmic particle distributions, observe dynamic Morton/Z-order space-filling curve partitioning, evaluate runtime load balancing across MPI ranks, and verify energy conservation and compute times.

## Positioning
Unlike generic scientific plotting tools or static offline renderers, the AL-BH web dashboard couples high-frame-rate Three.js WebGL particle rendering with real-time domain decomposition visualization (color-coded MPI ranks, bounding boxes, ghost-zone tracking) and live telemetry metrics (kinetic/potential energy, tree build vs force compute overhead, imbalance ratios).

## Operating Context
Used in computational physics research labs, HPC cluster post-processing, and academic evaluations. Works directly with simulation output artifacts (binary particle snapshots from `dump_particle_state()` and telemetry CSVs generated by AL-BH MPI/OpenMP runs), running in modern web browsers with WebGL support without requiring server-side runtime environments or complex build pipelines.

## Capabilities and Constraints
- **Capabilities:**
  - 3D interactive particle cloud rendering with orbital controls and timestep scrubbing/playback.
  - Spatial domain visualization showing Morton/Z-order curve paths, Octree bounding boxes, and MPI rank boundaries.
  - Telemetry charts and gauges for kinetic, potential, and total energy conservation, per-rank execution time, and load imbalance ratios.
  - Flexible downsampling for large-scale runs (e.g. 50k+ particles downsampled smoothly for client-side WebGL).
- **Constraints:**
  - Client-side WebGL performance constraints (smooth 60fps interaction on standard laptops/workstations).
  - Standalone portability: Zero external node/npm build dependencies; self-contained HTML/CSS/JS or generator output.
  - Precision: Accurately reflects physical coordinates, simulation units, and numerical metrics without visual distortion.

## Brand Commitments
- **Project Name:** AL-BH (Adaptive Linearized Barnes–Hut)
- **Subtitle:** A Cache-Aware, Dynamic Space-Filling Curve Framework for Distributed N-Body Simulations
- **Aesthetic Tone:** Scientific rigor meets sleek cosmic deep-space telemetry (dark mode, crisp typography, clean data overlays, legible contrast for scientific scrutiny).

## Evidence on Hand
- High-Performance C++ Simulation Core: Hybrid MPI + OpenMP Barnes–Hut engine (`src/`, `include/`).
- Simulation output generators and verification scripts: `scripts/evaluate_all_metrics.py`, `scripts/generate_web_viewer.py`.
- Benchmark configurations and Plummer sphere initial condition generators (`baselines/`, `tests/`).
- Three.js and OrbitControls libraries present in `viewer/assets/`.

## Product Principles
1. **Physical and Numerical Fidelity First:** Never sacrifice data accuracy or simulation truth for decorative visuals; coordinates, rank assignments, and energy metrics must reflect exact simulation telemetry.
2. **Instant Accessibility:** Zero build setup; standalone deliverables open directly in any standard modern web browser.
3. **Insight Through Dimensionality:** Connect 3D spatial dynamics directly with 2D performance metrics—clicking or scrubbing a timestep reveals both particle motion and MPI load balance simultaneously.
4. **Restraint and Legibility:** Prioritize scanability and dark-adapted scientific readability over distracting UI flair; UI elements recede to let the cosmic particles and critical telemetry lead.

## Accessibility & Inclusion
- High-contrast visual distinctions between MPI rank color codes, avoiding reliance solely on red-green channels.
- Full keyboard navigation for simulation playback controls (Space for play/pause, Arrow keys for step navigation).
- Clear tabular and numeric readouts alongside all graphical plots.
